MA-KAVOI Publishing Guide

News Publishing

  1. Create your article as a JSON file inside the articles folder.
  2. Add its filename to articles/index.json.
  3. Commit your changes on GitHub.
  4. Visit the News page to confirm publication.

Podcast Publishing

  1. Upload your audio to a public audio hosting service.
  2. Create an episode JSON file inside the podcasts folder.
  3. Add its filename to podcasts/index.json.
  4. Commit your changes and test the Podcast page.
